# MatchTalk

MatchTalk is an AI-powered second-screen companion for live soccer matches. It gives casual fans simple tactical explanations, match context, interactive questions, statistics, and predictions while a match is happening.

## Features

- Mobile-first home screen with live and upcoming matches
- Dynamic match detail pages
- Mock AI insights and contextual match chat
- “Explain That Play” interaction
- Match statistics and live win probability
- Fan polls and MatchTalk predictions
- Responsive dark sports-app design

## Tech stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Mock local data

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current scope

This is a UI-focused MVP. Match data, AI responses, and predictions are mocked; no authentication or external sports API is connected yet.
